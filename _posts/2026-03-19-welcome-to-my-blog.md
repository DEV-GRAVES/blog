Welcome to my blog! This is the first post on this site, built with [Jekyll](https://jekyllrb.com/) and hosted on [GitHub Pages](https://pages.github.com/).

## What to Expect

This blog will be a place where I share my thoughts, projects, and learnings. Stay tuned for more posts!

## About This Site

This site is powered by:

- **Jekyll** — a simple, static site generator
- **Minima** — Jekyll's default theme
- **GitHub Pages** — free hosting straight from this GitHub repository

## Getting Started Locally

Clone the repository and run:

```bash
bundle install
bundle exec jekyll serve
```

Then open your browser to `http://localhost:4000` to see the site locally.
